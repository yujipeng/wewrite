# 贴图视觉规范

## 画幅

- 主画幅 **3:4 竖图**（宽:高 = 0.75），生成时使用 `--size post`。
- 首图同时承担封面，主体放中间，四周留出裁切余量：
  - 1:1 裁切会切掉上下；
  - 16:9 / 2.35:1 裁切会切掉上下更多。
- 不要把关键文字贴到画面边缘 10% 以内。

## 统一性

同一组图至少统一三件事：

1. **色板**：一个主色 + 一个中性色，避免每张图换色调；
2. **光线**：同一时间/同一光源方向，夜景与日光不要混排；
3. **质感**：实拍、胶片、插画、3D 选一种，不混用。

## 构图

- 首图：主体占画面 50%–70%，背景干净，能一眼看懂主题；
- 细节图：靠近主体，保留可辨认的环境信息；
- 对比图：同一机位、同一焦段，只改变一个变量；
- 文字留白：需要后期加字时，预留上方或下方 1/4 的干净区域。

## 生成提示词

生成 3:4 竖图时，提示词包含：

```text
竖版 3:4 构图，[主体]，[环境]，[光线]，[色板]，[质感]，
主体居中，四周留白，无文字，无水印
```

避免：

- 要求模型生成大段中文（容易糊字）；
- 一张图里塞多个场景；
- 用“高级感”“ins风”这类无法执行的词替代具体光线和材质。

## 首图检查

- 缩小到信息流尺寸后，主体是否仍然可辨？
- 1:1 裁切后，主体是否完整？
- 与第二张并排时，是否能看出这是一组内容？
- 画面里是否出现未授权的品牌 logo、人脸或隐私信息？

## 与长文配图的区别

| | 长文配图 | 贴图 |
|---|---|---|
| 画幅 | 2.35:1 封面、16:9 内文 | 3:4 竖图 |
| 数量 | 封面 + 必要内文图 | 1–20 张，图片即内容 |
| 文字 | 图注可有可无 | 正文独立，图片承担叙事 |
| 排版 | 套主题 | 不排版 |
